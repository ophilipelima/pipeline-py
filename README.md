# Sobre o Projeto
O projeto consiste no desenvolvimento de um pipeline de Engenharia de Dados utilizando Python para integrar informações de duas fontes distintas, disponibilizadas nos formatos JSON e CSV.

O objetivo é demonstrar um processo de ETL (Extract, Transform, Load), contemplando a extração, padronização e consolidação de dados de diferentes estruturas em um único conjunto de dados.

A solução simula um cenário de integração de dados entre duas empresas que utilizam estruturas e nomenclaturas diferentes para armazenar informações sobre seus produtos e vendas.
